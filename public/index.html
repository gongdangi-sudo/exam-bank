문제은행 관리

여러 과목 ZIP이면: 📦 시험문제 ZIP 자동분리에서 ZIP 1개 + 공식 정답표 1개만 올리면 과목별 PDF를 자동 분리하고 정답을 연결합니다.

한 과목만이면: 공식 문제 원본 + 공식 정답표가 있으면 🏛 원본 문제 + 공식 정답표 등록을 사용하세요. 보기·표·박스를 원문 이미지로 그대로 보존합니다.

기존 방식: 여러 PDF를 한 번에 선택하면 문항을 자동 분리하고, 문제 안에 표시된 정답을 찾아 등록합니다. 등록 전 검수 화면에서 정답이 안 잡힌 문항만 수정하면 됩니다. 원문기출은 문제·보기 문구를 그대로 보존합니다. 응용기출은 같은 핵심쟁점을 유지한 별도 응용본을 저장해 선택 출제할 수 있습니다.

해설 편집실

ChatGPT에서 만든 해설 JSON을 가져온 뒤 여기서 문항별로 직접 수정할 수 있습니다. 저장된 내용은 문제 출제 → 해설지 보기에도 그대로 반영됩니다.

최상위 출제 규칙

정확성 우선: 조건을 확실히 충족하지 못한 문항은 출제하지 않습니다. 문항 수가 부족해도 임의 생성·추측·구법 문항을 채우지 않습니다.

국어·영어 문제·해설 세트 등록

원본 해설 우선
국어·영어는 문제편 PDF + 해설편 PDF를 한 세트로 등록합니다. 문항코드(A01, A02 등)를 기준으로 문제와 해설을 연결하며, AI가 원본 해설을 임의로 대체하지 않습니다.
브라우저 단독 버전에서는 PDF의 문항코드와 텍스트를 추출해 1차 매칭합니다. 이미지형/복잡한 편집 PDF에서 자동 인식이 불확실한 항목은 ‘검수 필요’로 남깁니다.

출제 이력

문제 등록

문제 원문은 변경하지 않습니다. 해설은 [정답 근거] → [보기별 O/X 상세 해설] → [핵심 정리] 순서로 작성하며, 법령·판례 문제는 현행 기준을 확인합니다.

시험문제 ZIP 자동분리

ZIP 안의 PDF를 과목별로 자동 분리하고, 공식 정답표의 같은 과목·책형 정답과 연결합니다.
ZIP 규칙: 행정학개론_가.pdf, 행정법총론_가.pdf처럼 과목명_책형.pdf이면 자동 인식합니다. 같은 이름의 HWP는 자동으로 무시하고 PDF만 사용합니다.
지원 과목은 자동 선택하고, 나머지 과목은 목록에만 표시합니다.

원본 문제 + 공식 정답표 등록

문제는 공식 원본 PDF를 좌표 기반으로 문제/보기/선택지 구조화하고, 정답은 공식 정답표 PDF에서 별도로 연결합니다.
권장 방식: 인사혁신처 등에서 배포한 문제 원본 PDF와 정답표 PDF를 각각 올립니다. 문제 본문·<보기>·선택지는 좌표 기반으로 텍스트 구조화합니다. 일반 객관식·ㄱㄴㄷ 보기형·○ 보기형·(가)(나)형은 텍스트를 우선하고, 표·그림처럼 실제로 텍스트 보존이 어려운 문항만 원본 이미지로 예외 처리합니다.
정상 문항은 문제 / 보기 / 선택지를 각각 텍스트로 저장합니다. 공단기 시험지에서는 새 출제 순서대로 문 1, 문 2 … 번호를 붙이고, 보기 박스까지 편집 가능한 텍스트로 출력합니다.

PDF 파일을 여러 개 끌어다 놓거나 클릭하세요Ctrl/Shift로 여러 파일을 한 번에 선택할 수 있습니다.
정답이 비어 있는 문항은 노란색 '확인 필요'로 표시됩니다. 정답만 입력한 뒤 전체 등록하면 됩니다. 이미 등록된 동일 문제는 자동으로 제외합니다.
