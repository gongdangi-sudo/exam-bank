문제은행 관리

여러 과목 ZIP이면: 📦 시험문제 ZIP 자동분리에서 ZIP 1개 + 공식 정답표 1개만 올리면 과목별 PDF를 자동 분리하고 정답을 연결합니다.

한 과목만이면: 공식 문제 원본 + 공식 정답표가 있으면 🏛 원본 문제 + 공식 정답표 등록을 사용하세요. 보기·표·박스를 원문 이미지로 그대로 보존합니다.

기존 방식: 여러 PDF를 한 번에 선택하면 문항을 자동 분리하고, 문제 안에 표시된 정답을 찾아 등록합니다. 등록 전 검수 화면에서 정답이 안 잡힌 문항만 수정하면 됩니다. 원문기출은 문제·보기 문구를 그대로 보존합니다. 응용기출은 같은 핵심쟁점을 유지한 별도 응용본을 저장해 선택 출제할 수 있습니다.

국어·영어 문제·해설 세트 등록 · K252

원본 해설 우선
국어·영어는 문제편 PDF + 해설편 PDF를 한 세트로 등록합니다. 문항코드(A01, A02 등)를 기준으로 문제와 해설을 연결하며, AI가 원본 해설을 임의로 대체하지 않습니다.
K252는 기존 분석 실패 상태값을 그대로 믿지 않고 저장된 문제 본문·제시문·선택지·정답을 다시 검사합니다. 정상 구조는 출제 가능으로 복구하고, 정답 누락·지문 누락·선택지 오류만 제외합니다.

원본 문제 + 공식 정답표 등록

문제는 공식 원본 PDF를 좌표 기반으로 문제/보기/선택지 구조화하고, 정답은 공식 정답표 PDF에서 별도로 연결합니다.
권장 방식: 인사혁신처 등에서 배포한 문제 원본 PDF와 정답표 PDF를 각각 올립니다. 문제 본문·<보기>·선택지는 좌표 기반으로 텍스트 구조화합니다. 일반 객관식·ㄱㄴㄷ 보기형·○ 보기형·(가)(나)형은 텍스트를 우선하고, 표·그림처럼 실제로 텍스트 보존이 어려운 문항만 원본 이미지로 예외 처리합니다.
정상 문항은 문제 / 보기 / 선택지를 각각 텍스트로 저장합니다. 공단기 시험지에서는 새 출제 순서대로 문 1, 문 2 … 번호를 붙이고, 보기 박스까지 편집 가능한 텍스트로 출력합니다.

문제은행 법령·판례 검수

문제은행 등록 단계에서 검수 · 국어·영어 기본 비대상 · 전체 JSON 일괄 검수 · L250
검수와 자동 제외는 별개입니다. 공식 근거를 확인한 결과만 승인하세요. 이 화면은 인터넷 법령을 자동 검색하지 않으며, AI가 돌려준 JSON도 담당자 승인 전에는 반영하지 않습니다.
원래 오답인 선택지, ‘구 ○○법’ 인용, 관련 없는 조문 개정만으로 제외하지 않습니다. 모든 보기의 판단·원문 정답·시행일·부칙을 대조해 영향 여부를 확인해야 합니다.
검수 요청·결과 저장에만 사용하는 날짜입니다.

국어·영어에는 기본 법령 검수를 요구하지 않습니다. 기존에 담당자가 명시적으로 승인한 보류·개정 제외 기록은 유지합니다. 기존 확인 기록은 출제 시 해당 기록의 기준일로 사용하며, 이 날짜나 시험 날짜를 바꾸어도 자동 취소하지 않습니다. 원문이 바뀌거나 새 개정 영향을 알게 되면 이 문제은행에서 다시 검수하세요. 검수 요청·결과 JSON은 현재 범위의 보류 문항 전체를 한 파일로 처리할 수 있습니다. 서버 저장은 안정성을 위해 내부적으로 50문항씩 나누어 저장·재확인합니다. 법령을 자동 검색하지는 않습니다.

L250: 화면 범위의 보류 문항을 한 JSON으로 내보내고 한 JSON으로 다시 가져옵니다. 저장은 서버에서 50문항씩 자동 분할되므로 사용자가 파일을 나눌 필요가 없습니다.
